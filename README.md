# EnziLink — Technician & Service Marketplace

**Tagline:** Connect Skills. Create Opportunities.

Bangladesh-first marketplace connecting customers directly with skilled workers across professions. EnziLink is a separate project under the EnziVolt parent brand.

## Current starter
- Responsive Bengali-first landing page
- Profession category selection
- Profession and area search interface (demo only)
- Customer / worker join modal (demo only)
- Job-posting entry point (demo only)
- Marketplace workflow explainer

## Important limitations
This is a static UI starter, not a production marketplace. It currently has no real authentication, database, worker directory, job persistence, messaging, payment, or admin portal. Demo forms do not transmit or store personal information.
