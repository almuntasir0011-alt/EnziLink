# EnziLink — Technician & Service Marketplace

**Tagline:** Connect Skills. Create Opportunities.

Bangladesh-first marketplace connecting customers directly with skilled workers across professions. EnziLink is a separate project under the EnziVolt parent brand.

## Current website / PWA starter
- Responsive Bengali-first landing page
- Profession category selection
- Profession and area search interface (demo only)
- Customer / worker join modal (demo only)
- Job-posting entry point (demo only)
- EnziVolt website entry point
- Web App Manifest, install prompt, and service worker offline shell
- Installable Progressive Web App (PWA) on supported browsers

## Important limitations
This is still a front-end prototype, not a production marketplace. It currently has no real authentication, database, worker directory, job persistence, messaging, payment, or admin portal. Demo forms do not transmit or store personal information. PWA installation availability depends on the browser and device.
